## 结论

1. **流程本身健康**：规划 2.2s（最大头）→ 检索 0.25s → 生成首 token 0.95s，全程约 3.4 秒，耗时合理。
2. **ES 关键词通道 0 命中**（⚠️ 实锤问题）：ES 未安装 ik 中文分词插件，standard 逐字分词导致中文短语匹配失效，目前检索完全依赖向量通道兜底。详见 TODO.md「ES 安装 IK 中文分词插件」。
3. **优化方向**：查询规划（2.2s）是最大瓶颈。简单问题可加启发式跳过 LLM 规划直接 DIRECT，约省 2 秒。
