# Argus RAG 知识库平台 — 需求文档

> 版本：1.0 ｜ 日期：2026-08-02 ｜ 状态：已实现（与当前代码一致）

---

## 1. 项目概述

### 1.1 背景

企业内部知识分散于各类文档（PDF、Word、Markdown、文本），员工检索困难、信息孤岛严重。通用大模型缺乏企业私有知识，存在幻觉与知识过时问题。Argus 旨在构建一个 **从底层自研的 RAG 知识库平台**，将私有文档与大语言模型深度融合，提供安全、可溯源、可管理的智能问答能力。

### 1.2 目标

| 目标 | 说明 |
|---|---|
| 知识入库自动化 | 上传即处理：解析 → 清洗 → 切块 → 向量化 → 关键词索引，全链路无人工干预 |
| 回答可信 | 混合检索 + 证据分级评估，证据不足主动拒答，回答附带引用溯源 |
| 多轮对话 | 知识库问答（有状态云端历史）+ AI 助手（Agent + 记忆）双形态 |
| 平台可管理 | 完整管理控制台：全局文档/群组、问答审计、检索质量、系统健康、操作留痕 |
| 数据隔离 | 群组级权限隔离，接口层强制成员校验 |

### 1.3 用户角色

| 角色 | 能力范围 |
|---|---|
| 普通用户（USER） | 加入群组、上传/检索文档、知识库问答、AI 助手对话、查看自己的问答历史 |
| 系统管理员（ADMIN） | 全部用户能力 + 管理控制台：全局文档/群组管理、问答历史审计、数据洞察、系统健康、审计日志、用户创建、模型配置 |

## 2. 功能需求

### 2.1 认证与账号（FR-AUTH）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-AUTH-1 | 注册 | 用户名/邮箱/显示名称/密码；用户名格式校验、保留字拦截、唯一性校验 |
| FR-AUTH-2 | 登录 | 用户名或邮箱 + 密码；失败统一提示"账号或密码错误"；禁用账号拒绝登录 |
| FR-AUTH-3 | 令牌体系 | Access Token（JWT，30 分钟）+ Refresh Token（httpOnly Cookie，14 天，一次性旋转、重放检测） |
| FR-AUTH-4 | 登出 | 吊销 refresh token、清除 cookie |
| FR-AUTH-5 | 修改密码 | 校验当前密码；新密码不可与当前相同 |
| FR-AUTH-6 | 账号切换 | 前端保存最近 5 个账号，一键切换 |
| FR-AUTH-7 | 强制改密 | 管理员创建/重置密码后，用户首次登录强制修改 |

### 2.2 协作小组（FR-GROUP）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-GROUP-1 | 创建群组 | 自动生成 12 位群组码；创建者为 OWNER |
| FR-GROUP-2 | 邀请成员 | OWNER 邀请、被邀请者接受/拒绝/取消 |
| FR-GROUP-3 | 加入申请 | 凭群组码申请，OWNER 审批 |
| FR-GROUP-4 | 成员管理 | 查看成员、OWNER 移除成员、成员退组（OWNER 不可退组） |
| FR-GROUP-5 | 数据隔离 | 文档、检索、问答严格限定群组范围；接口层强制成员校验，停用/解散群组拒绝访问 |

### 2.3 文档管理（FR-DOC）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-DOC-1 | 直接上传 | 单文件上传，上限 256MB，SHA-256 去重（同群组秒传） |
| FR-DOC-2 | 分片上传 | 5MB 分片、断点续传、MinIO 合并；会话 24h 过期（自动清理） |
| FR-DOC-3 | 格式支持 | PDF（Docling 版面解析）、DOCX、Markdown、TXT |
| FR-DOC-4 | 自动处理流水线 | 解析 → 清洗（保代码块）→ 结构化切块（标题/段落/句子，目标 240 token）→ 向量化 → ES 索引 |
| FR-DOC-5 | 处理状态 | UPLOADED/PROCESSING/READY/FAILED；失败可重试（指数退避，最多 3 次） |
| FR-DOC-6 | 文档操作 | 列表（群组/状态/文件名筛选）、预览（PDF 内嵌/文本/Markdown+公式）、下载、删除（级联清理切片/向量/ES/MinIO） |
| FR-DOC-7 | 去重与残留防护 | 同群组 hash 去重；删除后向量/索引清理失败会告警提示（防止残留影响检索） |

### 2.4 知识库问答（FR-QA）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-QA-1 | 提问 | 指定群组提问；问题长度 1-5000 |
| FR-QA-2 | 查询规划 | LLM 判定 DIRECT/REWRITE/DECOMPOSE，最多 3 条检索问句（DECOMPOSE 拆子问题） |
| FR-QA-3 | 并行混合检索 | PGvector 语义（top50）+ ES 关键词（top50）全并行 |
| FR-QA-4 | RRF 融合 | 平滑系数 K=60，融合后取 top 8，同文档相邻块聚类（±1 邻居扩展） |
| FR-QA-5 | 证据评估 | 四级：SUFFICIENT/PARTIAL/WEAK/NONE（向量相似度 <0.65 且无双通道命中 → NONE） |
| FR-QA-6 | 拒答 | NONE 直接返回"未检索到相关文档"，**不调用 LLM**（省成本） |
| FR-QA-7 | 回答生成 | 流式 SSE：token → answer → citations → done；回答基于证据、附带引用溯源 |
| FR-QA-8 | 云端历史 | 每次问答自动落库（问题/回答/引用/思考/拒答原因/证据级别）；支持回顾、**续聊**（追问追加同一会话）、删除 |
| FR-QA-9 | 用量统计 | 每次调用记录估算 Token/费用（按实际激活模型计价） |

### 2.5 AI 助手（FR-ASST）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-ASST-1 | 双模式 | CHAT（自由对话）+ KB_SEARCH（限定群组知识库检索问答，带引用） |
| FR-ASST-2 | Agent | LangGraph ReactAgent，KB_SEARCH 模式挂知识库检索工具（每轮限 1 次） |
| FR-ASST-3 | 会话管理 | 创建/重命名/删除（软删）/列表；SSE 流式 |
| FR-ASST-4 | 短期记忆 | 超 20 条消息或 8000 字符触发压缩——**LLM 语义摘要**（失败回退拼接） |
| FR-ASST-5 | 记忆可视化 | "AI 记住了什么"卡片展示摘要 + 更新时间 + 手动刷新 |
| FR-ASST-6 | 消息分页 | 游标分页（beforeId），长会话按需加载更早消息 |
| FR-ASST-7 | 会话归档 | 手动归档/恢复；30 天未活跃自动归档（惰性）；归档区可恢复/删除 |
| FR-ASST-8 | 自动标题 | 首次对话后 LLM 生成 2-6 字标题（用当前用户模型配置，失败不影响主流程） |
| FR-ASST-9 | 用量统计 | 助手调用计入 LLM 用量统计 |

### 2.6 管理控制台（FR-ADMIN，仅 ADMIN）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-ADMIN-1 | 全局文档管理 | 跨群组文档分页（群组/状态/文件名筛选）、状态统计卡、批量重试失败、删除（提示级联清理结果） |
| FR-ADMIN-2 | 全局群组管理 | 全量群组列表（含成员数）、详情（成员/文档/存储）、停用/恢复、移除成员、**解散**（级联清理） |
| FR-ADMIN-3 | 问答历史 | 全平台问答分页（按用户/群组筛选）、详情（问答/思考/引用/拒答原因）、拒答率 |
| FR-ADMIN-4 | 数据洞察 | 文档上传趋势、活跃用户趋势、格式分布、**检索证据质量分布**、拒答统计 |
| FR-ADMIN-5 | 系统健康 | PG/ES/MinIO/Embedding 连通性状态灯、处理队列（待处理/运行中/worker）、最近失败任务 |
| FR-ADMIN-6 | 审计日志 | 敏感操作留痕（删除/重试文档、停用/恢复/解散群组、移除成员、创建用户、状态变更、重置密码、模型配置变更），按操作筛选 |
| FR-ADMIN-7 | 用户管理 | 列表/详情/状态变更/密码重置 + **创建用户**（初始密码强制改密）+ **用量明细**（近 30 天） |
| FR-ADMIN-8 | LLM 用量统计 | 今日调用/Token/费用/成功率、30 天趋势（双 Y 轴）、用户/群组排行 |
| FR-ADMIN-9 | 模型配置 | 添加/激活/删除聊天与嵌入模型、连接测试；激活配置全局生效（含查询规划、记忆摘要、自动标题） |

### 2.7 系统与运维（FR-SYS）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-SYS-1 | 过期上传清理 | 每小时自动清理过期未完成上传会话（DB + MinIO 分片） |
| FR-SYS-2 | 启动自愈 | 启动时自动建表（幂等）、ES 索引检查、开发管理员种子 |
| FR-SYS-3 | 日志 | access 日志带 userId，可定位操作者；敏感操作错误级别记录 |

## 3. 非功能需求

### 3.1 安全

| 项 | 要求 |
|---|---|
| 认证 | JWT + Refresh 旋转 + bcrypt 密码哈希；密码长度 ≤72 字节 |
| 授权 | 群组成员校验（`require_group_access`）；文档归属校验不信任客户端 groupId；管理员旁路；上传会话归属校验 |
| 数据隔离 | 检索（向量/ES）均按 group_id 过滤 + 接口层双重校验 |
| 敏感操作 | 审计留痕 |
| 前端安全 | DOMPurify 消毒所有 Markdown 渲染；链接新窗口打开 |
| 密钥 | `.env.example` 仅占位符；JWT 密钥可配置 |

### 3.2 性能

| 场景 | 目标 |
|---|---|
| 混合检索 | 双通道并行，典型 <2s（含 embedding 调用） |
| 证据不足拒答 | NONE 短路，不调用 LLM（从 ~10s 降至 ~3s） |
| 问答总耗时 | 主要受 LLM 生成速度限制（流式输出） |
| 大文件上传 | 分片并发上传 + MinIO 服务端合并 |
| 长会话 | 消息游标分页，按需加载 |

### 3.3 可靠性与可维护性

| 项 | 说明 |
|---|---|
| 非关键路径隔离 | 落库、审计、用量统计失败不阻断主流程（try/except 吞并 + 日志） |
| 幂等建表 | create_all + `ADD COLUMN IF NOT EXISTS`，无迁移工具亦可演进 |
| 清理任务 | 后台周期任务独立、可取消 |
| 检索残留防护 | 删除失败有 error 日志 + 用户提示；检索排除已删文档的证据 |
| 文档 | CLAUDE.md、README、需求/设计文档、审查修复报告持续维护 |

### 3.4 可用性

- 前端全站中文（Element Plus zh-cn）
- 流式打字机效果（token 级）
- 数学公式 KaTeX 渲染（问答/助手/文档预览）
- 云端历史跨设备可查（刷新不丢）

## 4. 需求边界（当前不做）

| 项 | 说明 |
|---|---|
| 多租户/SaaS | 当前为单实例部署 |
| 全文权限细分 | 仅群组级隔离，无文档级 ACL |
| Agent 多工具 | 工具扩展已列入 TODO（文档/群组管理工具、多工具协作、调用可视化） |
| 移动端 | 响应式可用，无独立 App |
| 知识库自动纠错 | 失败文档仅支持手动重试 |
